# Sonic Fluid 🌊

> An interactive audio-reactive fluid simulation built with WebGL and the Web Audio API.

Sonic Fluid transforms ambient sound and music into real-time fluid dynamics and flowing ink.

##  Features
- **Fluid Dynamics**: Real-time Navier-Stokes fluid physics running on WebGL2.
- **Audio-Reactive**: Analyzes live audio and frequency spectra in real time via the Web Audio API.
- **Interactive Controls**: Multiple color modes (Math, Organic, Hybrid), flow styles (Watercolor, Ink, Mixed), quality presets, and simulation physics sliders.
- **Pure Web Standards**: Zero dependencies, 100% client-side HTML5, WebGL2, and JavaScript.

##  Usage
Open `index.html` in any modern web browser with WebGL2 support. Tap the canvas to enable microphone input and watch the fluid react to sound.
